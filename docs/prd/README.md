# PRD Index

One entry per PRD in this directory. Before writing a new PRD, scan this
index for overlapping scope: extend the existing PRD instead of creating a
near-duplicate.

| PRD | Scope |
|-----|-------|
| [agent-markdown](agent-markdown.md) | Agent-readable access to the whole blog: a plain Markdown twin for every page URL via a `.md` suffix across all languages and listing pages, a site-level `/llms.txt` discovery index, and alternate links from HTML pages, kept in sync with published content. |
| [tag-navigation](tag-navigation.md) | Tag-based browsing across the blog: a master-detail Tags page (tag list plus the selected tag's articles, shareable per-tag URLs), linked tag chips on articles, and contextual related-article lists for the current article's tags on desktop and mobile, derived from one authoritative tag source in the content repository. |
